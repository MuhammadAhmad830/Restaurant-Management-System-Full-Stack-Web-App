# 🍕 Restaurant Management System — Full Stack Web App

A full-stack web application built with **ASP.NET Core Blazor Server** and **.NET 8**, 
currently deployed and live at **Pizza Palace, Faisalabad**.

## 🚀 Features
- 📊 Live Sales Dashboard (Daily / Monthly / Yearly)
- 🧾 Order Terminal with Receipt Printing
- 📦 Inventory Tracking & Alerts
- 🍽️ Menu Items & Categories Management
- 🪑 Table Status Management
- 🔐 Session-based Login System

## 🛠️ Tech Stack
- **Frontend:** Blazor Server (.NET 8)
- **Backend:** C# / ASP.NET Core
- **Database:** PostgreSQL + Entity Framework Core
- **ORM:** EF Core
